# kino harvester

Расширение Chrome (MV3), которое собирает карточки фильмов с выдачи Кинопоиска
в JSON для `kino import kp`.

## Зачем оно ещё существует

Основной путь наполнения базы — `kino update kp`: каталог отдаёт 250 фильмов за
один запрос и приносит рейтинги, id и список сервисов. Расширение осталось для
подборок, которые фильтрами API не выражаются: листаешь глазами — оно собирает.

## Безопасность

```json
"permissions": ["storage"]
```

Сетевых разрешений нет **вообще**. Расширение физически не может ничего
отправить наружу, даже если бы код попытался. Данные лежат в `chrome.storage`
до тех пор, пока их не выгрузят кнопкой.

## Установка

1. `chrome://extensions` → включить «Режим разработчика»
2. «Загрузить распакованное расширение» → выбрать папку `extension/`

## Использование

1. Открыть любую выдачу kinopoisk.ru — поиск, топ-250, подборку
2. Листать. Расширение собирает карточки со всех просмотренных страниц
3. Иконка расширения → «Скачать JSON»
4. `kino import kp ~/Downloads/kino-harvest.json`

Фильтр по рейтингу выключен по умолчанию: рейтинг виден лишь на части карточек
(в реальной выгрузке — на 64 из 788), и включённый фильтр выбрасывал 94% сбора.

## Что парсится

Название и год достаются из подписи карточки. Формат у Кинопоиска
непоследовательный, поддерживаются оба варианта:

```
Побег из Шоушенка (The Shawshank Redemption, 1994)
Побег из Шоушенка. 1994, США, драма
```

Сериалы («сериал», «мини-сериал», «видео», «ТВ») **отбрасываются**: в базе
живут только фильмы, и сериал, отправленный в поиск TMDB по фильмам, прилипнет
к случайному однофамильцу.

## Чего расширение не делает намеренно

Не пишет `onlineViewOption` — ключ отсутствует в выгрузке целиком. Со страницы
выдачи доступность онлайн не видна, а `watch_online = 0` от источника, который
не знает ответа, затирает реальные данные: один раз так стёрлось наличие 120
фильмов. Молчание в JSON означает «не знаю», ноль означал бы «нет».
