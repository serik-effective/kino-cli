# Продукт

CLI на Go для личного использования. Собирает и хранит локально данные о фильмах из TMDB + OMDb + Kinopoisk, чтобы агенты/скрипты читали быстро и без сети.

## Юзкейсы (в порядке приоритета)
1. «Цифровые релизы за последнюю неделю» → обновить локальную БД.
2. То же + фильтр по рейтингу/голосам («digital за неделю, TMDB ≥6.5, голосов ≥50»).
3. Быстрый локальный запрос к уже собранной БД (без сети), вывод table/json/csv.
4. Обогащение записей рейтингами IMDb/Metacritic/RT (OMDb) и КП (kinopoisk.dev).

## Не в скоупе (пока)
Сериалы, торренты/ссылки на просмотр, вебморда, синк с Plex/Jellyfin, планировщик (cron делает ОС).

## Принципы
- Оффлайн-first: любой `list` работает без сети.
- Идемпотентность: повторный `update` за тот же период не плодит дубли.
- Бюджет запросов: OMDb 1000/сут, KP 200/сут (free) → обогащение отдельным шагом, с лимитом и очередью.
